## 一、前置条件

### 需要什么

| 项 | 说明 |
|---|---|
| **Bingus Shared Loader** | v15 或更新，**并开启 addon 支持** |
| 游戏版本 | 构建 25480438 / exe 1.8.46015.0（其他版本会被拒绝） |

### 确认 loader 正常

打开日志：

```
<游戏目录>\BingusSharedLoader.log
```

**第一行应该是：**

```
Bingus Shared Loader loader-v18; API 1
```

**看到 `API 1` 就说明 addon 支持已开启。**

## 二、安装步骤

### 1. 彻底退出游戏

**要结束进程**，不是回主菜单。

> 这是为了让上一次的还原逻辑跑完，也避免文件被占用。

### 2. 删掉旧的 Extra 条目

**如果你之前装过这个 mod 的旧版本，先在管理器里删掉。**

**多套系统同时运行会互相覆盖** —— 这是排查问题时最常见的原因。

### 3. 导入 mod

从 `dist/25x24/` 里选你想要的：

**每个 zip = 一个技能的独立 mod。**

**建议第一次先装 2-3 个**，比如：

```
021 → 121 MG Sentry.zip          哨戒机枪带什么
066 → 066 Gatling Sentry.zip     加特林哨戒炮带什么
124 → 124 Reinforce.zip          增援带什么
```

### 4. 每个下拉里选一项

**导入后，管理器里每个 mod 显示一个下拉。**

下列标题形如 `What MG Sentry brings`，里面 24 项形如 `Bring [088] EXO-84`。

**各选一个。**

### 5. Deploy → 启动游戏

**改任何一个选择，都要重新 Deploy。**

## 三、怎么选才有用

### ★ 核心规则

> **授予的战略配备，只有你「还没有」的时候才看得见。**

**这是最重要的一条。** 理解它就不会白折腾。

| 情况 | 结果 |
|---|---|
| 授予的配备**你还没有** | ✅ 看得见 |
| 授予的配备**你已解锁但没装备** | ✅ 看得见 |
| 授予的配备**你正好装备着** | ❌ 看不见（重复，不会多出来） |

### 推荐优先选这些

**这几类通常解锁较晚，最容易看到效果：**

| 编号 | 名称 |
|---|---|
| 088 | EXO-84 “破门者”外骨骼装甲 |
| 010 | EXO-49 “解放者”外骨骼装甲 |
| 091 | EXO-51 “伐木者”外骨骼装甲 |
| 027 | EXO-45 “爱国者”外骨骼装甲 |
| 026 | M-103 补给型快速侦察载具 |
| 105 | M-102 快速侦察载具 |
| 147 | EAT-17 一次性反坦克武器 |
| 001 | TD-220 “堡垒”坦克 |

### 验证方法（推荐先做一次）

**先只装一个 mod，选一个你确定没有的授予，进任务看是否出现。**

**确认机制工作后，再逐步加更多 mod。**

## 四、验证是否生效

### 看日志

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\
```

**两个文件：**

#### `ExtraEngine-STATUS.txt`

```
OK - extra stratagems assigned

mod      : ExtraEngine v2.0.0
phase    : done
status   : applied
picks    : 2 host(s) requested an extra
last why : applied 2 record(s)
```

#### `ExtraEngine-applied.txt`

**逐条的写入结果：**

```
host   3  +200 49 -> 88  OK
host 147  +200  0 -> 66  OK
```

**读法：** `宿主编号 原值 -> 新值 结果`

### 看游戏内

**进任务后，打开战略配备列表 —— 额外的那几个应该在列表里。**

> 注意：额外是**跟随宿主**的。宿主必须在你这一局携带的技能里，
> 它才会交付自己的额外（**增援是例外，它每局必然在场**）。

## 五、常见问题

### 「MOD CONFLICTS」警告

**误报，点 Got it 忽略即可。**

管理器比对的是**选项路径**（`Option 1 -> Suboption 1`），
而这 25 个 mod 每个都只有一个下拉，路径当然一样。

**真正的冲突只有两种：**
- 两个 mod 的 `Include` 指向**同一个文件夹**
- 两个 mod 改**同一个宿主**

**这 25 个：文件夹全不同、宿主全不同 → 不会冲突。**

### 装了但没多出东西

**按顺序排查：**

1. **授予的配备你是不是已经有了？** ← **最常见原因**
2. **宿主带上了吗？** 额外跟着宿主走，宿主不在场就不会交付
3. **授予的配备是不是你正在装备着？** 那就看不见（重复）
4. **看 `ExtraEngine-applied.txt`** —— 是否显示 OK
5. **是不是还装着旧的 Extra 版本？** 全部删掉重来

### 日志显示 `waiting_for_settings`

**正常状态** —— 设置表还没载入。**进一次任务即可。**

**最多等约 2 分钟**，超时会显示 `gave_up`。

### 日志显示 `game_dll_hash_mismatch`

**游戏更新了，mod 主动拒绝运行** —— 这是保护机制，不是 bug。

**等 mod 更新适配新版本。**

### 技能消失了 / 配装异常

**这通常是多套系统互相覆盖导致的。**

1. **彻底退出游戏**（会触发还原）
2. **禁用所有 Extra 相关 mod**
3. 重新 Deploy，启动，确认恢复
4. 再一个一个加回来

## 六、卸载与还原

### 正常卸载

1. 退出游戏（**会还原全部原始值**）
2. 在管理器里删掉这些 mod
3. Deploy

**mod 不写任何磁盘文件** —— 所有改动只在内存里，退出即还原。

### 如果怀疑没还原

**彻底退出游戏一次即可** —— 还原逻辑在 `shutdown` 时执行。

**极端情况下**：重启游戏会重新载入干净的设置表。
