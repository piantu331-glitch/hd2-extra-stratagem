# 如何重建 / Rebuild

## 环境

- Node.js 18+（生成器与校验器）
- 游戏内的 `bin\lua51.dll`（用于语法与运行验证）

## 步骤

```sh
# 1. 生成 25 个 mod 的结构与 600 个叶子脚本
node tools/gen_grid9.js       # 写出 build/grid9.json + build/grid9/*/entry.lua

# 2. 打包成 25 个独立 zip
node tools/build_grid9.js     # 写出 delivery/25个独立下拉/*.zip

# 3. 规范命名（文件名 + 显示名 + 下拉项名）
node tools/rename_mods.js
node tools/rename_entries.js

# 4. 校验：25 个 mod × 24 项 = 600 项
node tools/verify_entries.js
```

**`tools/gen_grid9.js` 与 `tools/build_grid9.js` 里的路径是绝对路径，
在其他机器上运行前请改成你自己的项目根目录。**

## 校验器会检查什么

`tools/verify_entries.js` 对全部 600 个下拉项逐一核对：

- 标签格式为 `Bring [编号] 简称`
- **标签编号 == 文件夹编号 == 脚本里实际写入的授予编号**
- 宿主编号和 mod 一致
- 按编号升序、无自授
- **共享引擎只有一个声明**（`mods/dsh/xcore`）

`tools/conflict_check.js` 检查 25 个 mod 之间有没有真正的冲突：

- 有没有两个 mod 共用 `Include` 文件夹
- 有没有两个叶子用同一个资源名
