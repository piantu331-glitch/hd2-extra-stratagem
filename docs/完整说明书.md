# 一、这是什么

给《绝地潜兵 2》用的一个 **Lua 注入式 mod**（跑在 Bingus Shared Loader 上）。

**作用**：让你带的技能**额外再带一个战略配备**。

**形式**：25 个下拉菜单，每个 24 个选项 —— 一共 600 种组合，各组独立。

```
[4] Orbital Gatling        <- 选一个
[18] Eagle Airstrike       <- 选一个
[66] Gatling Sentry        <- 选一个
[124] Reinforce            <- 选一个
... 共 25 组
```

**含义**：`[18] Eagle Airstrike` 那一组你选了 `Orbital Napalm`
→ 你带「飞鹰空袭」时，**额外多拿一个「轨道凝固汽油弹火力网」**。

# 二、⚠️ 使用前必读

| 项 | 说明 |
|---|---|
| **反作弊风险** | 运行时修改游戏内存，**可能违反游戏 ToS** |
| **仅客户端** | 队友**看不到**你的额外配备 |
| **建议场景** | 单人 / 知情固定队 |
| **是否写磁盘** | **否**。退出游戏**完全还原** |
| **版本变更** | 校验 `game.dll` 的 SHA-256，**不符则拒绝运行** |
| **责任** | 自担风险 |

**我不建议在公开匹配里用。** README 里的这段声明**请不要删**。

# 三、安装

## 前置

**Bingus Shared Loader v15+**，并开启 addon 支持。
（日志在 `BingusSharedLoader.log`，能看到 `API 1`）

## 步骤

1. **彻底退出游戏**（结束进程，不是回主菜单）
2. 删掉旧的 Extra 相关条目（避免冲突）
3. 导入 `dist/Extra-Full-25x24.zip`
4. **25 个下拉各选一个**
5. **Deploy**
6. 启动游戏 → 进任务

> **改任何一个选择都要重新 Deploy。**

# 五、用之前要知道的三件事

### ① 有 4 个宿主是引擎自己的记录

```
kind 18  飞鹰空袭     原本 +200 = 49
kind 30  飞鹰机枪扫射  原本 +200 = 49
kind 65  飞鹰集束炸弹  原本 +200 = 49
kind  3  飞鹰 500KG   原本 +200 = 49
```

引擎原本各给它们**一个「49 号」额外**。本 mod **会把那个换成你选的**。

**额外的数量不变**，只是内容变了。日志里会显示 `49 -> NN`。

**其余 21 个宿主原本就是 0，属于纯新增。**

### ② 宿主必须带上才生效

额外是**跟着宿主走**的。

- 带「飞鹰空袭」→ 才拿到你给飞鹰空袭配的那个额外
- 想多拿几个 → **就把对应的宿主都带上**

### ③ 别指望重复叠加同一个

引擎对**同一种额外会去重**。所以每组各配一个**不同的**才划算。

# 六、验证是否生效

日志目录：

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\
```

**文件名格式**：`All_h<宿主kind>g<授予kind>-STATUS.txt`

例如 `All_h018g106-STATUS.txt` 就是「飞鹰空袭(18) → 轨道凝固汽油弹(106)」。

**成功时看到**：

```
OK - one extra Tank per carried stratagem

mod      : All_h018g106 v1.0.0
phase    : done
status   : applied
```

**逐条结果**在同名的 `-applied.txt`：

```
targets=1 wrote=1 skipped=0 missing=0 failed=0
Eagle Airstrike                kind  18  +200 49 -> 106  OK
```

**失败时的状态**：

| status | 含义 | 怎么办 |
|---|---|---|
| `waiting_for_settings` | 设置表还没载入 | 进一次任务；最多等约 2 分钟 |
| `game_dll_hash_mismatch` | 游戏版本变了 | **正常保护**，等 mod 更新 |
| `gave_up` | 一直没就绪 | 把 `-STATUS.txt` 发出来 |
| `write_failed` | 写入失败 | 发 `-applied.txt` |

# 七、原理

## 数据结构

```
*(game.dll + 0x348E8F8)  ->  80280 字节的战略配备设置表
     ↓
11 个 LDLD 组，共 149 条记录，每条 400 字节
     ↓
每条记录：
  +0    kind（编号）
  +4    id
  +168  音效资源名哈希
  +176  图标资源名哈希
  +200  「额外附带哪个战略配备」   ← 本 mod 改的就是这里
```

## 为什么改 `+200` 就能多带一个

**引擎自己已经在用这个字段** —— 149 条里有 10 条的 `+200` 已经是 `49`，
意思是「这条技能额外附带 49 号战略配备」。

**本 mod 只是给「你选的技能」也写上值。**

## 已知限制（实测）

| 事实 | 说明 |
|---|---|
| `+200` 是**标量** | 写 4 个值只出 1 个（实测过） |
| **可以叠加** | 带 N 个挂了额外的技能 → N 个额外 |
| **全量 149 条会崩** | 实测：配装整个失效，技能全消失 |
| **安全范围** | 十几条以内，且要有明确依据 |

**所以这个 mod 走的是「小范围、有依据」的路子。**

# 八、kind 编号是怎么查出来的

**这是本项目的核心方法，不是猜的。**

每条记录里存着**它自己资源的名字哈希**。用 [Filediver](https://github.com/xypwn/filediver)
导出游戏资源列表，哈希就能翻成文件名，**文件名直接说明这是哪个技能**：

```
kind  58  +168 = orbital_railcannon      ->  轨道炮攻击
kind 121  +176 = ...turrets_machinegun   ->  A/MG-43 哨戒机枪
```

## 完整步骤（游戏更新后可重跑）

### 1. 下载 Filediver

```
https://github.com/xypwn/filediver/releases/latest
-> filediver-cli-windows.zip
```

解压，`filediver.exe` 和 `ffmpeg.exe` 放一起。

### 2. 导出资源列表

```powershell
cd <filediver目录>
$g = "C:\AAAyingyong\steam\steamapps\common\Helldivers 2"
.\filediver.exe --gamedir $g --list -i "*stratagem*" > stratagem_list.txt
.\filediver.exe --gamedir $g --list -i "*eagle*"     > eagle_list.txt
.\filediver.exe --gamedir $g --list -i "*orbital*"   > orbital_list.txt
```

> ⚠️ PowerShell 重定向写的是 **UTF-16**，读的时候要 `.toString('utf16le')`
> ⚠️ **不要用 Node 的 `execFileSync` 抓输出** —— 沙箱禁止管道 stdio（EPERM）

### 3. 导出汉化名（要中文名的话）

```powershell
.\filediver.exe --gamedir $g --out cn --xaml-format raw -i "*localization/generated/stratagems_cn*"
.\filediver.exe --gamedir $g --out us --xaml-format raw -i "*localization/generated/stratagems_us*"
```

得到 `stratagems_cn.xaml.main`，**跳过前 16 字节**再当 UTF-8 读：

```
<sys:String x:Key="nui_stratagem_orbital_railcannon_name">轨道炮攻击</sys:String>
```

### 4. dump 记录里的哈希

读 `*(game.dll + 0x348E8F8)` 那块 80280 字节，按 400 字节一条切，
取每条的 `+168` 和 `+176`。

### 5. 配对

`+168`/`+176` 的值 → 资源名 → **就是技能名**。

**88 / 149 条能这样解出名字。**

# 九、踩过的坑（避免重犯）

| 坑 | 教训 |
|---|---|
| **全量 149 条一起改** | **配装会崩**，技能全消失。只改必要的那几条 |
| **靠猜 kind** | 我猜哨戒炮是 47/95/60、飞鹰是 76/78/79/129 —— **全错** |
| **「加了没反应」当判据** | **无效**。非装备项加了也没反应，推不出任何结论 |
| 用 `+56` 字段分类 | 只能分出轨道类，剩下 117 条分不开 |
| 用 `+104` 浮点分组 | **巧合**，不是分类键 |
| 手写 hex 字面量 | **必须脚本生成**，手分会掉字节 |
| Node 抓子进程输出 | 沙箱 EPERM，**用 PowerShell 重定向** |
| 读 UTF-16 文件 | 要 `.toString('utf16le')` |

# 十、出问题怎么办

## 配装异常 / 技能消失

1. **彻底退出游戏**（会触发还原）
2. **禁用这个 mod**
3. 重新 Deploy
4. 启动，确认恢复

**如果没恢复**：说明还原没跑到。把日志目录整个打包发出来。

## 日志在哪

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\
```

看 `All_hNNNgNNN-STATUS.txt` 和 `-applied.txt`。

## 常见 status 对照

| status | 含义 |
|---|---|
| `waiting_for_settings` | 正常等待，进任务即可 |
| `game_dll_hash_mismatch` | 游戏更新了，**保护性拒绝** |
| `gave_up` | 超时未就绪 |
| `write_failed` | 写入失败 |
| `runtime_error` | 脚本报错，看 detail |

# 十一、安全设计

- **`game.dll` SHA-256 校验** —— 版本不符**拒绝运行**，不会写错位置
- **完整遍历 80280 字节**，边界检查，要求**恰好 149 条记录**
- **写入前把整块表读两遍比对**
- **只写目标记录的 `+200` 一个 dword**
- **`+200` 已非 0 的记录跳过，不覆盖**
- **明确拒绝 `MEM_IMAGE`** —— **绝不改代码段**
- **每次写入立即回读验证**
- **退出游戏时还原全部原始值**

# 十三、自己重建

```powershell
node tools/gen_grid3.js          # 生成 build/grid3.json + 600 份脚本
node tools/build_addon.js `
  --name mods/dsh/extra_full `
  --choices build/grid3.json `
  --guid <你的UUID> `
  --display-name "Full Stratagem Choice" `
  --output dist/Extra-Full-25x24.zip
node tools/verify_short.js dist/Extra-Full-25x24.zip
```

**已验证可复现**：重跑生成的 zip 与 `dist/` 里的**字节完全一致**。

**校验器会检查全部 600 份**：归档存在、能解包、宿主/授予配对正确、
**每个下拉标签和脚本内容一致**。
